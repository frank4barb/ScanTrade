# ScanTrade 📈

**ScanTrade** è un framework in Python ideato per la ricerca, ottimizzazione e simulazione (backtesting) di formule e strategie di compravendita su ETF, volte alla massimizzazione del profitto.

## 🚀 Obiettivi del Progetto
- **Ricerca Automatica di Strategie**: Identificazione delle migliori regole di ingresso/uscita mediante parametri tecnici e strategie quantitative.
- **Backtesting Accurato**: Simulazione storica considerando capitale iniziale, commissioni e gestione del rischio.
- **Analisi delle Performance**: Calcolo di indicatori chiave (ROI, Sharpe Ratio, Max Drawdown, Win Rate).

## 🛠️ Struttura del Progetto
- `main.py`: Punto di ingresso dell'applicazione e verifica ambiente.
- `SPEC.md`: Specifiche di progetto e registro dello storico modifiche.

## 📦 Installazione e Avvio
```bash
python main.py
```
